# مسار — MASAR

The public website of MASAR, a customer-management system for travel and tourism companies in Iraq.

This repository holds only the built site (`index.html`, its images and fonts), served by GitHub Pages at
https://www.masariq.tech/ — the source is kept private. Open-source licences of the bundled libraries are in
